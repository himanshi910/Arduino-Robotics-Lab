# Arduino-Robotics-Lab

This repository contains my Arduino and robotics learning work, including
basic electronics, sensors, motors, actuators, and communication protocols.

The experiments were developed and tested using simulation platforms such as
Tinkercad and Wokwi.

## Topics Covered

- C/C++ Programming Basics
- Arduino Basics
- Sensors
- Potentiometer and Analog Input
- PWM
- DC Motors and Motor Drivers
- Servo Motors
- Stepper Motors
- Communication Protocols

## Tools and Platforms

- Arduino
- Tinkercad
- Wokwi
- VS Code
- C/C++
