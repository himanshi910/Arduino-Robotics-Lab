# Project
This project demonstrates a basic safety and obstacle-detection system using an ultrasonic sensor and a DC motor.

The idea is to automatically stop the motor when an object comes too close, providing a simple safety mechanism to prevent possible collisions or damage. The HC-SR04 ultrasonic sensor continuously detects the distance of an approaching object, and the Arduino controls the DC motor accordingly.

# Technologies Used
Tinkercad
Arduino C/C++
Arduino UNO
HC-SR04 Ultrasonic Sensor
L293D Motor Driver
PWM Motor Control
Digital Input/Output

# How to Run
Connect the components according to the pin configuration.
Connect the Arduino UNO to the computer.
Open the .ino file in Arduino IDE.
Select Arduino UNO as the board.
Upload the program.
Turn the slide switch ON.
Place an object at different distances from the HC-SR04 sensor.
Observe the LED indicators and motor behavior.
